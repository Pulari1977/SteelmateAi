SteelMate AI - version history
==============================

1.9.1  (2026-11-07)
- Finds Tekla installed in C:\TeklaStructures\<version> (no space) even when Tekla is closed.
- Much more detail in mcp.log: every Tekla call, the connection attempt, and full errors.
- Errors about Tekla files now say which Tekla folder was used.

1.9.0  (2026-11-07)
- New: "Connect to Claude Desktop" button (Settings). Use your Claude Pro/Max plan with no API key:
  it adds SteelMate's Tekla tools to the Claude desktop app, and you chat there.
  Your existing Claude Desktop settings are kept, and a backup is saved next to them.
- Error messages explain that a Claude Pro/Max plan is not an API key, and point to the button above.
- The ui, agents and sample tool are now kept in the source code too.

1.8.0  (2026-11-07)
- Connects to the AI by itself at startup. No need to press anything once a key is saved.
  - Picks up keys from Windows environment variables (ANTHROPIC_API_KEY, OPENAI_API_KEY, GEMINI_API_KEY).
  - Uses a vendor that has a key (Claude first) if the chosen one has none.
- Model lists for Claude, OpenAI and Gemini now come live from each vendor, so new models appear
  automatically and retired ones disappear. If your chosen model is retired, it switches to a current one.
- The connection check is free (it reads the model list, no tokens used).
- Status bar shows both links, e.g. "Claude: connected · Tekla: 58 tools".
- Finds Tekla 2025/2026 on any drive and in custom folders (Windows installed-programs list).
- Removed the installer's "Tekla not found" warning (it only checked one folder).

1.7.0  (2026-11-07)
- Works with Tekla Structures 2025 and 2026 automatically. No separate build per version.
  SteelMate AI uses the Tekla that is running; if none is running, the newest installed (2025 or newer).
  If you switch Tekla version while SteelMate AI is open, press Reconnect on the Tools tab.
- The Tekla API files are no longer shipped with the app. They are loaded from your Tekla installation.
- IFC export now writes IFC4 (the same call works in 2025 and 2026; IFC2x3 export is gone in 2025).
- The "not connected" message now says which Tekla version and folder are in use.
- The installer warns if Tekla 2025/2026 is not found, and removes old pinned Tekla files on update.

1.6.0  (2026-11-07)
- New: Setup.exe installer and uninstaller (Windows "Apps" list shows the version).
- Claude is the default AI (claude-sonnet-5-5). Old settings are moved to Claude once.
- Chat works even when Tekla is not connected (before, the app refused to call the AI).
- "Save and reconnect" tests the API key straight away and reports the result.
- AI errors explained in plain words: wrong key, no credit, wrong model, blocked network, busy.
- Pasted API keys are cleaned (spaces, quotes, line breaks).
- Missing Tekla helper files are loaded from the installed Tekla Structures bin folder.

1.5.2  (2026-11-06)
- Your original build (from D:\SteelMateAi). AI calls were blocked when Tekla was not connected.
